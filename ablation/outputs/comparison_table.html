Key Findings

1. CSBC pipeline detects 100% of CSBC-type bugs (5/5) — including 3 bugs where the official spec provides NO description of the correct behavior.
2. Bare LLM & Claude Agent only detect single-file, spec-described bugs (2/5 CSBC) — they cannot track cross-chunk signal relationships.
3. Cross-Chunk Only matches Full Pipeline on CSBC bugs — the core detection comes from internal cross-spec consistency, not from Layer 2 spec alignment.
4. Phase 3 (Codex) finds 3 additional bugs missed by all other methods — reggen template errors and fault-injection vulnerabilities that require source-level inspection.
5. CSBC blind spots: single-block copy-paste (err_code), shared prim internals (Bug 019), single-module atomicity (rv_dm) — need Channel S/Z for full coverage.
